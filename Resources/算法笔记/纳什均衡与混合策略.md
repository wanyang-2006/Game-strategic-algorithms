# 纳什均衡与混合策略

## 一、概述

在之前的笔记中，我们主要讨论了**完全信息**的序贯博弈（如 Minimax、Alpha-Beta）。但在很多博弈场景中（如石头剪刀布、扑克、不完全信息博弈），不存在确定性的最优策略。此时需要引入**纳什均衡（Nash Equilibrium）** 和**混合策略（Mixed Strategy）** 的概念。

---

## 二、基本概念

### 1. 博弈的标准型（策略型）表示

一个博弈可以用一张**收益矩阵（Payoff Matrix）** 来表示。以两人博弈为例：

**石头剪刀布的收益矩阵（对玩家 1）：**

|  | 石头 | 剪刀 | 布 |
|:---:|:---:|:---:|:---:|
| **石头** | 0 | 1 | -1 |
| **剪刀** | -1 | 0 | 1 |
| **布** | 1 | -1 | 0 |

行代表玩家 1 的策略，列代表玩家 2 的策略，表中数字是玩家 1 的收益。

### 2. 纯策略与混合策略

- **纯策略（Pure Strategy）**：确定性地选择某个动作，如"始终出石头"
- **混合策略（Mixed Strategy）**：以一定概率分布在多个动作上随机选择，如"1/3 概率出石头，1/3 出剪刀，1/3 出布"

形式化地，混合策略是动作集合上的概率分布 $\sigma = (p_1, p_2, \ldots, p_k)$，满足 $\sum p_i = 1$。

### 3. 期望收益

如果玩家 1 使用混合策略 $\sigma_1$，玩家 2 使用 $\sigma_2$，则玩家 1 的期望收益为：

$$E[u_1] = \sum_{i}\sum_{j} \sigma_1(i) \cdot \sigma_2(j) \cdot u_1(i,j)$$

## 三、纳什均衡

### 1. 定义

**纳什均衡** 是一个策略组合 $(\sigma_1^*, \sigma_2^*)$，满足：

> 任何一个玩家**单方面**改变自己的策略，都不能获得更高的收益。

形式化：

$$u_1(\sigma_1^*, \sigma_2^*) \geq u_1(\sigma_1, \sigma_2^*) \quad \forall \sigma_1$$
$$u_2(\sigma_1^*, \sigma_2^*) \geq u_2(\sigma_1^*, \sigma_2) \quad \forall \sigma_2$$

### 2. 纳什定理

> **每个有限博弈都至少存在一个（混合策略）纳什均衡。**

这是约翰·纳什在 1950 年证明的，也是他获得诺贝尔经济学奖的核心贡献。

### 3. 示例分析

#### 石头剪刀布

唯一的纳什均衡是：双方都以 $(\frac{1}{3}, \frac{1}{3}, \frac{1}{3})$ 的概率随机出招。

此时双方的期望收益都是 0，任何偏离此策略都会被对手利用。

#### 囚徒困境

|  | 合作 | 背叛 |
|:---:|:---:|:---:|
| **合作** | (-1, -1) | (-3, 0) |
| **背叛** | (0, -3) | (-2, -2) |

唯一的纳什均衡是：**双方都选择背叛**（-2, -2）。

尽管双方合作 (-1, -1) 对双方都更好，但这不是均衡——任何一方都有动机偏离合作。

#### 猎鹿博弈（Stag Hunt）

|  | 猎鹿 | 猎兔 |
|:---:|:---:|:---:|
| **猎鹿** | (5, 5) | (0, 3) |
| **猎兔** | (3, 0) | (3, 3) |

存在两个纯策略纳什均衡：
- 双方都猎鹿 (5, 5)
- 双方都猎兔 (3, 3)

还有一个混合策略均衡。

## 四、混合策略纳什均衡的求解

### 1. 2×2 博弈的求解方法

考虑一般的 2×2 博弈：

|  | L | R |
|:---:|:---:|:---:|
| **U** | $(a, e)$ | $(b, f)$ |
| **D** | $(c, g)$ | $(d, h)$ |

设玩家 1 以概率 $p$ 选择 U，玩家 2 以概率 $q$ 选择 L。

**关键思想：** 在混合策略纳什均衡中，每个玩家都必须让对手对自己的各个纯策略**无差异**（indifferent）。

玩家 2 让玩家 1 无差异：
$$q \cdot a + (1-q) \cdot b = q \cdot c + (1-q) \cdot d$$

解出 $q$：
$$q = \frac{d - b}{(a - b) - (c - d)}$$

类似地，玩家 1 让玩家 2 无差异：
$$p \cdot e + (1-p) \cdot g = p \cdot f + (1-p) \cdot h$$

解出 $p$。

### 2. 求解示例：匹配硬币

|  | 正面 | 反面 |
|:---:|:---:|:---:|
| **正面** | (1, -1) | (-1, 1) |
| **反面** | (-1, 1) | (1, -1) |

玩家 2 让玩家 1 无差异：
$$q \cdot 1 + (1-q) \cdot (-1) = q \cdot (-1) + (1-q) \cdot 1$$
$$2q - 1 = 1 - 2q$$
$$4q = 2 \Rightarrow q = \frac{1}{2}$$

对称地，$p = \frac{1}{2}$。

纳什均衡：双方各以 50% 概率选正面或反面，期望收益为 0。

## 五、极小化极大定理（Minimax Theorem）

### 冯·诺依曼极小化极大定理（1928）

> 在二人零和博弈中，存在一个值 $V$（博弈值），使得：
> - 玩家 1 有一个混合策略保证期望收益 $\geq V$
> - 玩家 2 有一个混合策略保证玩家 1 的期望收益 $\leq V$
>
> $$\max_{\sigma_1} \min_{\sigma_2} E[u_1] = \min_{\sigma_2} \max_{\sigma_1} E[u_1] = V$$

这个定理说明了零和博弈中混合策略纳什均衡的存在性和唯一值。

**与 Minimax 搜索的关系：** 完全信息博弈中的 Minimax 算法就是这个定理在博弈树上的应用。

## 六、在游戏 AI 中的应用

### 1. 扑克 AI（不完全信息博弈）

在德州扑克等不完全信息游戏中，最优策略必须是混合策略。

- **CFR（Counterfactual Regret Minimization）** 算法：通过迭代最小化遗憾值来逼近纳什均衡
- Libratus 和 Pluribus（卡内基梅隆大学的扑克 AI）使用 CFR 变体
- 核心思想：在每个信息集上维护一个策略分布，逐步收敛到均衡

### 2. 安全策略与可利用性

- **纳什均衡策略** 是"不可被利用的"（unexploitable）——对手无法通过改变策略获利
- 但在实际中，如果对手不是最优的，纳什均衡可能不是"最赚钱的"
- 实际 AI 往往在**均衡策略**和**剥削策略（exploitative strategy）** 之间权衡

### 3. 多人博弈

- 纳什均衡的概念自然推广到多人博弈
- 但多人博弈的纳什均衡可能有多个，且不一定可交换
- 计算多人博弈的纳什均衡是 PPAD-complete 问题（计算复杂度很高）

## 七、计算纳什均衡的方法

| 方法 | 适用范围 | 复杂度 |
|:---:|:---:|:---:|
| 无差异条件法 | 2×2 博弈 | 解方程组 |
| 支撑枚举法 | 小规模博弈 | 指数级 |
| Lemke-Howson 算法 | 二人博弈 | 最坏指数级 |
| 线性规划 | 二人零和博弈 | 多项式时间 |
| CFR 算法 | 大规模序贯博弈 | 迭代逼近 |

## 八、Python 简单实现：2×2 博弈求解

```python
import numpy as np

def solve_2x2_zero_sum(payoff_matrix):
    """
    求解 2x2 零和博弈的混合策略纳什均衡
    payoff_matrix: 2x2 numpy array (玩家1的收益)
    返回: (p, q, V) - 玩家1选行1的概率, 玩家2选列1的概率, 博弈值
    """
    a, b = payoff_matrix[0]
    c, d = payoff_matrix[1]

    # 检查是否有纯策略均衡
    denom = (a - b - c + d)
    if denom == 0:
        return None  # 退化情况

    # 玩家1的混合策略
    p = (d - c) / denom
    # 玩家2的混合策略
    q = (d - b) / denom
    # 博弈值
    V = (a * d - b * c) / denom

    # 确保概率在 [0, 1] 范围内
    if 0 <= p <= 1 and 0 <= q <= 1:
        return p, q, V
    else:
        return None  # 无内部混合策略均衡

# 示例：匹配硬币
payoff = np.array([[1, -1],
                   [-1, 1]])
result = solve_2x2_zero_sum(payoff)
if result:
    p, q, V = result
    print(f"玩家1选策略1的概率: {p:.4f}")
    print(f"玩家2选策略1的概率: {q:.4f}")
    print(f"博弈值: {V:.4f}")
```

## 九、总结

| 概念 | 要点 |
|:---:|:---:|
| 纯策略 | 确定性地选择一个动作 |
| 混合策略 | 以概率分布随机选择动作 |
| 纳什均衡 | 没有玩家能通过单方面改变策略获利 |
| 零和博弈 | Minimax 定理保证均衡存在且值唯一 |
| 实际应用 | 扑克 AI、安全策略设计、机制设计 |

纳什均衡为我们提供了一个"稳定"的策略概念——即使对手知道你的策略，你也不会吃亏。这在对抗性 AI 和不完全信息博弈中至关重要。
