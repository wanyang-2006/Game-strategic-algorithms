# 蒙特卡洛树搜索（Monte Carlo Tree Search, MCTS）

## 一、算法概述

**蒙特卡洛树搜索（MCTS）** 是一种基于随机采样的博弈树搜索算法。与 Minimax/Alpha-Beta 依赖精确的评估函数不同，MCTS 通过大量随机模拟（rollout）来估计各个动作的胜率，从而选择最优行动。

MCTS 的核心优势在于：
- **不需要精确的评估函数**：只需要知道游戏规则和终局结果
- **适用于高分支因子的游戏**：如围棋（分支因子约 250）
- **渐近最优**：给予足够时间，MCTS 会收敛到最优策略

MCTS 是 AlphaGo 的核心算法之一，它与深度神经网络的结合彻底改变了计算机围棋。

## 二、四个核心步骤

MCTS 的每一轮迭代包含以下四个步骤：

### 1. 选择（Selection）

从根节点开始，沿着树向下选择子节点，直到到达一个尚未完全展开的节点。选择策略需要在**探索（Exploration）** 和**利用（Exploitation）** 之间取得平衡。

最经典的选择策略是 **UCB1（Upper Confidence Bound）**：

$$UCT(v_i) = \frac{w_i}{n_i} + c \sqrt{\frac{\ln N}{n_i}}$$

其中：
- $w_i$：子节点 $i$ 的胜利次数
- $n_i$：子节点 $i$ 的访问次数
- $N$：父节点的访问次数
- $c$：探索常数（通常取 $\sqrt{2}$）

第一项（$\frac{w_i}{n_i}$）是利用项——选择胜率高的节点；第二项是探索项——鼓励访问较少的节点。

### 2. 扩展（Expansion）

当到达一个未完全展开的节点时，随机选择一个未被探索的合法动作，创建对应的子节点并加入树中。

### 3. 模拟（Simulation / Rollout）

从新扩展的节点开始，使用某种策略（通常是随机策略）快速进行一局完整的对弈，直到游戏结束，得到一个胜负结果。

### 4. 回溯（Backpropagation）

将模拟结果沿着从叶节点到根节点的路径向上传播，更新路径上每个节点的访问次数和胜利次数。

```
         [选择]
        根节点 → 沿 UCT 最优路径向下
           ↓
         [扩展]
        创建新子节点
           ↓
         [模拟]
        随机对弈至终局
           ↓
         [回溯]
        更新路径上的统计信息
```

## 三、算法伪代码

```
function MCTS(rootState):
    create root node v0 with state rootState

    while within computational budget:   // 在时间/迭代次数限制内
        // 1. 选择
        vl = TreePolicy(v0)

        // 2-3. 扩展 + 模拟
        result = DefaultPolicy(vl.state)

        // 4. 回溯
        Backpropagate(vl, result)

    return bestChild(v0)  // 返回访问次数最多的子节点


function TreePolicy(v):
    while v is not terminal:
        if v is not fully expanded:
            return Expand(v)          // 扩展
        else:
            v = BestChild(v, c)       // 选择（UCT）
    return v


function DefaultPolicy(state):
    while state is not terminal:
        action = random choice from legal actions
        state = apply(state, action)
    return result(state)              // 返回胜/负/平


function Backpropagate(v, result):
    while v is not null:
        v.N = v.N + 1                // 访问次数 +1
        v.W = v.W + result           // 累加结果
        v = v.parent
```

## 四、C++ 实现框架

```cpp
#include <cmath>
#include <vector>
#include <cstdlib>
#include <climits>

struct MCTSNode {
    GameState state;
    MCTSNode* parent;
    std::vector<MCTSNode*> children;
    int visits = 0;
    double wins = 0.0;
    int action;  // 导致此状态的动作

    bool isFullyExpanded() const;
    bool isTerminal() const;
};

// UCT 选择最优子节点
MCTSNode* bestChildUCT(MCTSNode* node, double c = 1.414) {
    MCTSNode* best = nullptr;
    double bestValue = -1e9;
    for (auto* child : node->children) {
        double uct = (child->wins / child->visits)
                   + c * std::sqrt(std::log(node->visits) / child->visits);
        if (uct > bestValue) {
            bestValue = uct;
            best = child;
        }
    }
    return best;
}

// 随机模拟
double rollout(GameState state) {
    while (!state.isTerminal()) {
        auto moves = state.getLegalMoves();
        int idx = rand() % moves.size();
        state.applyMove(moves[idx]);
    }
    return state.getResult();  // 1.0 胜, 0.0 负, 0.5 平
}

// 回溯更新
void backpropagate(MCTSNode* node, double result) {
    while (node != nullptr) {
        node->visits++;
        node->wins += result;
        result = 1.0 - result;  // 交替视角
        node = node->parent;
    }
}

// MCTS 主循环
int mctsSearch(GameState rootState, int iterations) {
    MCTSNode* root = new MCTSNode{rootState, nullptr, {}, 0, 0.0, -1};

    for (int i = 0; i < iterations; i++) {
        // 1. 选择
        MCTSNode* node = root;
        while (!node->isTerminal() && node->isFullyExpanded()) {
            node = bestChildUCT(node);
        }

        // 2. 扩展
        if (!node->isTerminal()) {
            // 创建新子节点（省略具体实现）
            node = expand(node);
        }

        // 3. 模拟
        double result = rollout(node->state);

        // 4. 回溯
        backpropagate(node, result);
    }

    // 选择访问次数最多的子节点
    MCTSNode* best = nullptr;
    int bestVisits = -1;
    for (auto* child : root->children) {
        if (child->visits > bestVisits) {
            bestVisits = child->visits;
            best = child;
        }
    }

    int bestAction = best->action;
    // 释放树内存（省略）
    return bestAction;
}
```

## 五、MCTS 与 Minimax 的对比

| 特性 | Minimax + Alpha-Beta | MCTS |
|:---:|:---:|:---:|
| 需要评估函数 | ✅ 必须（且质量至关重要） | ❌ 不需要（只需终局判定） |
| 适合低分支因子 | ✅ 非常适合（象棋等） | ✅ 可以，但无优势 |
| 适合高分支因子 | ❌ 难以应对 | ✅ 围棋的首选 |
| 搜索结果确定性 | ✅ 确定性结果 | ❌ 带有随机性 |
| 任意时刻可中断 | ❌ 需完成整层搜索 | ✅ 随时可返回当前最优 |
| 渐近最优 | ✅ 完全搜索时最优 | ✅ 无限迭代时最优 |

## 六、重要变体与改进

### 1. RAVE（Rapid Action Value Estimation）

利用"所有先前模拟中某动作的全局胜率"来加速收敛。适用于围棋等游戏。

### 2. 结合神经网络（AlphaGo / AlphaZero 方案）

- 用**策略网络（Policy Network）** 替代随机 rollout，指导选择和扩展
- 用**价值网络（Value Network）** 替代模拟，直接评估局面
- 训练方式：自我对弈 + 强化学习

$$UCT(v_i) = \frac{w_i}{n_i} + c \cdot P(v_i) \cdot \frac{\sqrt{N}}{1 + n_i}$$

其中 $P(v_i)$ 是策略网络给出的先验概率。

### 3. 并行化 MCTS

- **叶并行（Leaf Parallelization）**：多个线程同时进行 rollout
- **根并行（Root Parallelization）**：多棵独立的 MCTS 树，最后合并结果
- **树并行（Tree Parallelization）**：共享一棵树，使用虚拟损失（Virtual Loss）避免冲突

## 八、MCTS 的优缺点

### 优点
- 不依赖于领域特定的评估函数
- 天然支持任意时刻终止并返回当前最优
- 对搜索空间大的问题（围棋、多人游戏）表现优异
- 容易并行化

### 缺点
- 每次迭代需要完整的模拟，可能较慢
- 随机 rollout 的质量对性能影响较大
- 对于状态空间较小的游戏，不如 Alpha-Beta 高效
- 存在偏差——某些罕见但关键的变化可能被忽略

---

## 九、总结

MCTS 是现代博弈 AI 的重要基石。它的核心思想——**通过随机采样估计价值，在探索和利用之间平衡**——不仅适用于棋类游戏，也被广泛应用于规划、优化等领域。结合深度学习后（如 AlphaZero），MCTS 展现出超越人类的博弈能力。
