## 🔴 **高危问题**

### 1. **`resetBoard()` 函数中的致命错误**
**位置**: [Chess::resetBoard()](Chinese_Chess_trial_1.cpp#L788-L830)

**问题描述**:
```cpp
for (int mpos = 0; mpos < BOARDWIDTH * BOARDHEIGHT; mpos++)
{
    currState.push_back(boardInfo[pos2x(mpos)][pos2y(mpos)]);
}
```

**缺陷**:
- `boardInfo` 是局部二维数组，作用域结束后自动释放
- `currState` 推送的是副本，但问题在于状态向量初始化后没有充分验证

**建议修复**:
```cpp
// 应该确保初始化完成后验证棋盘合法性
void Chess::resetBoard()
{
    vector<Grid> currState;
    Grid boardInfo[BOARDWIDTH][BOARDHEIGHT];
    // ... 初始化代码 ...
    state.clear();
    state.push_back(currState);
    
    // 添加验证：检查是否有恰好2个将/帅
    validateBoardLegality();
}
```

### 2. **`makeMoveAssumeLegal()` 缺少关键约束验证**
**位置**: [Chess::makeMoveAssumeLegal()](Chinese_Chess_trial_1.cpp#L1057-L1115)

**问题描述**:
虽然函数名表示"假设合法"，但以下约束未被验证：

#### 2.1 象的眼睛检查缺失
```cpp
// ❌ makeMoveAssumeLegal 中没有检查象眼是否被塞住
// 但 generateMoves 中有检查
case Bishop:
{
    int ex = x + dx_bishop_eye[dir], ey = y + dy_bishop_eye[dir];
    auto &eGrid = state[currTurnId][xy2pos(ex, ey)];
    if (eGrid.color != EMPTY) {
        continue; // ← 这个检查在 makeMoveAssumeLegal 中没有
    }
}
```

#### 2.2 马的蹩脚检查缺失
```cpp
// ❌ makeMoveAssumeLegal 中没有检查马脚是否被阻挡
case Knight:
{
    int fx = x + dx_knight_foot[dir], fy = y + dy_knight_foot[dir];
    auto &fGrid = state[currTurnId][xy2pos(fx, fy)];
    if (fGrid.color != EMPTY) {
        continue; // ← 这个检查在 makeMoveAssumeLegal 中没有
    }
}
```

#### 2.3 兵卒的过河约束缺失
```cpp
// 生成着法时检查了过河条件
bool crossMidLine = (curGrid.color == RED ? (y > 4) : (y < 5));
// 但 makeMoveAssumeLegal 完全没有验证这一点
// 允许兵在未过河时能够左右移动
```

**风险**:
- 允许象穿过被塞住的象眼
- 允许马穿越被阻挡的马脚
- 允许兵越线前进行非法移动

### 6. **被攻击判定中的潜在逻辑缺陷**
**位置**: [attacked()函数 - King处理](Chinese_Chess_trial_1.cpp#L1177-1182)

**问题**:

```cpp
{
```


## 🔧 **修复代码示例**

### 添加到 Chess 类中:

```cpp
bool Chess::validateBoardLegality() {
    // 计数将/帅
    int redKingCount = 0, blackKingCount = 0;
    
    for (int x = 0; x < BOARDWIDTH; x++) {
        for (int y = 0; y < BOARDHEIGHT; y++) {
            auto &grid = state[currTurnId][xy2pos(x, y)];
            
            if (grid.type == King && grid.color == RED) redKingCount++;
            if (grid.type == King && grid.color == BLACK) blackKingCount++;
            
            // 象必须在己方半场
            if (grid.type == Bishop) {
                if (grid.color == RED && !inColorArea(x, y, RED)) return false;
                if (grid.color == BLACK && !inColorArea(x, y, BLACK)) return false;
            }
            
            // 士必须在九宫
            if (grid.type == Assistant) {
                if (grid.color == RED && !inKingArea(x, y, RED)) return false;
                if (grid.color == BLACK && !inKingArea(x, y, BLACK)) return false;
            }
        }
    }
    
    return redKingCount == 1 && blackKingCount == 1;
}

// 在 makeMoveAssumeLegal() 的末尾添加:
bool Chess::makeMoveAssumeLegal(const Move &move) {

    // 执行移动后进行验证
    if (!validateBoardLegality()) {
        undoMove();
        return false;
    }
    
    return true;
}
```
